# Playwrite_java

## Description:
This is a simple test framework with only one direct purpose - investigate and practice playwright automation tool.

## Tech stack:
- Java -v 21
- playwright
- TestNG

## Preconditions:
- Install playwright browsers: 
````
   mvn exec:java -e -D exec.mainClass="com.microsoft.playwright.CLI" -D exec.args="install msedge"
````
